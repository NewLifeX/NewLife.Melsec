## Обзор

**NewLife.Melsec** — это полностью управляемая библиотека связи для ПЛК Mitsubishi, построенная на основе стандартной спецификации интерфейса **NewLife.IoT**. Она охватывает три основных семейства протоколов — последовательный протокол FxLinks, протокол Ethernet MC (кадры 3E/1E/4E) и протокол SLMP — с поддержкой мультитранспорта TCP/UDP/Serial. Библиотека распространяется по лицензии MIT и не имеет зависимостей от коммерческих компонентов.

Через унифицированный интерфейс `IDriver` она может быть интегрирована в шлюзовые платформы **ZeroIoT/IoTEdge** одной строкой кода.

## Ключевые особенности

- **Полное покрытие протоколов**: Полная реализация FxLinks последовательный (BR/WR/BW/WW), кадров MC Ethernet 3E/1E/4E (двоичный+ASCII), кадров SLMP 3C
- **Полностью управляемая реализация**: Без зависимости от HslCommunication или других коммерческих библиотек, только стандартные библиотеки .NET
- **Интеграция с экосистемой IoT**: Соответствие спецификациям NewLife.IoT v2.6+ `IDriver`/`IDriverParameter`/`INode`
- **Оптимизация пакетного чтения**: Алгоритм `BuildSegments` автоматически объединяет соседние адреса
- **Поддержка нескольких станций**: Несколько ПЛК могут совместно использовать одно последовательное соединение
- **Преобразование типов данных**: `ConvertToWords` поддерживает Boolean/Int16/Int32/Float/Double → UInt16[]
- **Расширенные возможности**: Кадры 4E, произвольное чтение, удаленный RUN/STOP, блокировка паролем, регистрация монитора
- **APM трассировка**: Распределенная трассировка через `ITracer`
- **Кроссплатформенность**: 9 целевых фреймворков от `net45` до `net10.0`

## Поддержка протоколов

| Протокол | Транспорт | Поддерживаемые серии ПЛК | Статус |
|:--------:|:---------:|:-------------------------|:------:|
| FxLinks | RS-485 последовательный | Серия FX | ✅ Завершено |
| MC 3E (Binary/ASCII) | TCP/IP | Q, iQ-R, L, FX5U | ✅ Завершено |
| MC 1E | TCP/IP | Серия A | ✅ Завершено |
| MC 4E | TCP/IP | Серия iQ-R | ✅ Завершено |
| MC (UDP/Serial) | UDP / последовательный | Мультитранспорт | ✅ Завершено |
| SLMP 3C | TCP/IP | iQ-R, iQ-F | ✅ Завершено |

## Часто задаваемые вопросы

**В: Почему чтение FxLinks возвращает null?**  
О: Причина — несоответствие параметров последовательного порта (скорость передачи/четность) или тайм-аут связи.

**В: Какие режимы транспорта поддерживает протокол MC?**  
О: Поддерживаются три режима: TCP (по умолчанию), UDP и последовательный.
