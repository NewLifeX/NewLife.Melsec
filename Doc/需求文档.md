# NewLife.Melsec 需求文档

> 版本：v2.0 | 日期：2026-07-22

本文档描述 NewLife.Melsec 的愿景、核心目标和功能方向。完成状态在[功能清单](功能清单.md)中追踪，详细设计在[架构设计](架构设计.md)中展开。

## 1. 背景与愿景

### 1.1 系统定位

三菱 PLC（MELSEC 系列）是工业自动化领域的主流设备，广泛应用于制造、冶金、交通、水处理等行业。上位机程序与三菱 PLC 通信时，主要面临两类协议场景：RS-485 串口（FxLinks 计算机链路协议）和 TCP 以太网（MC 协议）。

NewLife.Melsec 是基于 **NewLife.IoT** 标准接口规范的三菱 PLC 纯托管通信库，覆盖上述两大协议场景，同时扩展支持 SLMP 最新协议标准。整个库采用 MIT 开源协议，不依赖任何商业授权组件，支持 Windows/Linux/macOS，可在 ARM 边缘设备上运行。作为 NewLife 物联网生态的驱动组件，可无缝对接 ZeroIoT 平台与 IoTEdge 网关。

### 1.2 愿景

成为 .NET 生态下功能最完善、性能最优、文档最清晰的三菱 PLC 通信库。开发者 5 行代码即可实现与三菱 PLC 的读写通信，无需关注底层协议细节；IoTEdge 网关可通过标准 `IDriver` 接口直接挂载，零配置接入工业数据采集平台。

## 2. 核心目标

| 编号 | 目标 | 所属层级 | 一句话描述 |
|------|------|----------|------------|
| SYS | 系统基础 | 基础层 | 协议无关的公共组件与工具，支撑所有协议模块 |
| FXL | FxLinks 计算机链路协议 | 核心层 | 通过 RS-485 串口与 FX 系列 PLC 进行位/字数据读写 |
| MC | MC 协议 3E/1E 帧 | 核心层 | 通过 TCP 以太网与 Q/iQ-R/L/FX5U 系列 PLC 通信 |
| SLMP | SLMP 协议 3C 帧 | 核心层 | 最新三菱以太网协议标准，兼容更广泛设备族 |

## 3. 功能需求

### 3.1 SYS — 系统基础

- **SYS-1 HexHelper 十六进制工具类**：16 进制字符与字节互转方法。
- **SYS-2 SerialTransport 串口传输层**：串口收发封装，异步发送等待、超时、粘包处理。
- **SYS-3 SerialPortConfig 串口配置持久化**：串口参数 XML 序列化与反序列化。
- **SYS-4 MelsecNode 节点模型**：`INode` 通用节点模型，FxLinks/MC 共用。
- **SYS-5 标签名（Tag）访问**：点位名→地址映射字典，支持别名访问。

### 3.2 FXL — FxLinks 计算机链路协议（RS-485 串口）

- **FXL-1 ControlCodes 控制码枚举**：ENQ/STX/ETX/ACK/NAK/EOT 等控制码。
- **FXL-2 ErrorCodes FxLinks 错误码**：校验错误、协议错误、PLC 号错误等。
- **FXL-3 NetworkErrorCodes 网络错误码**：通信超时、站号错误、格式错误等。
- **FXL-4 FxLinksMessage 请求帧编解码**：BR/WR/BW/WW 四种操作命令的帧结构。
- **FXL-5 FxLinksResponse 响应帧解析**：STX 读响应、ACK 写确认、NAK 写失败。
- **FXL-6 FxLinks 协议栈**：串口管理、命令发送、超时处理、APM 埋点。
- **FXL-7 FxLinksException 异常类**：协议异常封装。
- **FXL-8 FxLinksDriver 驱动接口**：`IDriver` 实现，批量读取分段优化。
- **FXL-9 FxLinksParameter 驱动参数**：串口参数、站号、批量参数配置。

### 3.3 MC — MC 协议（以太网）

- **MC-1 DeviceCodes 软元件代码枚举与地址解析**：20+ 软元件代码及地址解析器。
- **MC-2 MCMessage 3E 帧请求编解码**：二进制模式 3E 帧序列化/反序列化。
- **MC-3 MCResponse 3E 帧响应解析**：结束码检查、字/位数据解析。
- **MC-4 MCProtocol 协议栈**：TCP 长连接管理、自动重连、线程安全。
- **MC-5 MCErrorCodes 错误码与异常**：7 种结束码枚举及 MCException。
- **MC-6 MCDriver 驱动接口**：`IDriver` 实现，批量读取分段+数据转换。
- **MC-7 MCParameter 驱动参数**：IP/Port、网络号、批量参数配置。
- **MC-8 ConvertToWords 数据类型转换**：Boolean/Int16~Double 转字数组。
- **MC-9 MC 3E ASCII 模式帧**：ASCII 十六进制模式编解码，兼容 Q 系列 ASCII 设备。
- **MC-10 MC 1E 帧编解码（A 系列）**：A 兼容 1E 帧格式，老旧 A 系列 PLC 通信。
- **MC-11 MCDriver 支持 1E 模式切换**：枚举参数切换 3E/1E 模式。
- **MC-12 多类型数据转换增强**：ReadInt32/ReadUInt32/ReadSingle/ReadDouble/ReadString 读取解析。
- **MC-13 UDP 传输支持**：MCProtocol 新增 UDP 传输模式。
- **MC-14 MC 串口协议（1C/3C/4C）**：MCProtocol 串口模式，复用 3E/1E 帧格式。
- **MC-15 随机读取（Random Read）**：MC 3E 命令 0403h 随机读取。
- **MC-16 远程控制（RUN/STOP）**：MC 协议远程 PLC 启停。
- **MC-17 MC 4E 帧支持**：4E 帧（扩展帧）编解码，子头 5400h/D400h，含序列号字段，兼容 iQ-R 系列。

### 3.4 SLMP — SLMP 协议 3C 帧

### 3.4 SLMP — SLMP 协议 3C 帧

- **SLMP-1 SLMP 协议 3C 帧支持**：SLMP 3C 帧封装，与 MC 3E 二进制兼容。

## 5. 不做什么

- 不实现 PLC 编程接口（GX Works 通信协议）
- 不实现 OPC UA/DA 服务器
- 不实现 Modbus 转换（由 NewLife.Modbus 项目承担）
- 不依赖任何商业授权库（包括 HslCommunication）
- 旧版 `MelsecDriver.cs` + `MelsecParameter.cs` 已从编译排除，全部功能由 `FxLinksDriver` + `MCDriver` 纯托管替代
